## API 응답 구조 확인 (12장 #7·#8)

(2026-11-25 첫 호출, 클라우드 세션에서 확인)

- 장애인 고용직무분류 `/job_code`: 3,369행. `jobCdNm` 이 직종명, `jobCdLevel` 이 계층(0~5)이다. `jobCd` 자릿수가 계층과 같이 늘어난다
  (예: `5` 대분류 → `53` → `532` → `5323` → `532300` → `53230100`). `jobTask`(하는 일)·`simlrJob`(유사 직업)은 **5단계(8자리)에만** 있다.
  응답은 표준 형식(`header/resultCode=0000`, `item`, `totalCount`).
- NCS `/ncsCdInfo`: 1,096행. 세분류 코드(`dutyCd`) = `ncsLclasCd+ncsMclasCd+ncsSclasCd+ncsSubdCd` 8자리.
  응답 형식이 다르다(`dataInfo/code=000`, `row`, `totCnt`) → `data_go_kr.py` 가 두 형식을 모두 읽게 고쳤다.
- NCS `ncsKsaInfo.gbnName` 값 종류: **수행준거·지식·기술·태도** 4가지. 누락 점검에는 수행준거만 쓴다.
